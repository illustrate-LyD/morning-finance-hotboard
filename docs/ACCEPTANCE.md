# 晨间财经热榜 · 验收标准（v0.2）

验收窗口：北京时间当日约 23:00（首轮）/ 次日 07:00 后（日常）。
手机端响应式的完整设计说明与逐项验收见 [`MOBILE.md`](./MOBILE.md)（2026-11-23）。

## 必须通过
1. 打开页面可见 **7 个源卡片**（美股、X·AI、A股、央行·财政、商品·期货、地缘政治、Polymarket）。
2. 每个源 **恰好或最多 10 条**。宽屏（≥1024px）与中屏保持框内滚动，默认视口约露出 **1–5**（或略多），框内滚动可见 6–10。窄屏竖屏（<640px）展开全部条目，不使用卡内滚动。
3. 每条有 **可点击标题链接**（`https`），新标签打开；窄屏上整行（含备注）均为同一热区，高度不少于 48px。
4. 顶栏显示 **北京时间更新日期/约 07:00 更新**（或当日快照时间）。
5. 底栏四个外链：华尔街见闻、财联社、Reuters、Bloomberg。
6. 某源失败时该卡显示「暂无更新」，**不影响其他源**。
7. 同日数据与聊天「晨间财经简报」来自 **同一份 JSON 快照**。
8. 深色主题；排名 1–3 有视觉强调。
9. 手机端（Android Chrome 与 iOS Safari，竖屏 + 横屏）按 `MOBILE.md` §9 通过：360 宽无横向溢出、来源跳转条不遮挡卡片标题、尊重安全区与 `100dvh`、桌面 1280 外观不回退。
