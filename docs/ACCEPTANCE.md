# 晨间财经热榜 · 验收标准（v0.1）

验收窗口：北京时间当日约 23:00（首轮）/ 次日 07:00 后（日常）。

## 必须通过
1. 打开页面可见 **7 个源卡片**（美股、X·AI、A股、央行·财政、商品·期货、地缘政治、Polymarket）。
2. 每个源 **恰好或最多 10 条**；默认视口约露出 **1–5**，框内滚动可见 6–10。
3. 每条有 **可点击标题链接**（`https`），新标签打开。
4. 顶栏显示 **北京时间更新日期/约 07:00 更新**（或当日快照时间）。
5. 底栏四个外链：华尔街见闻、财联社、Reuters、Bloomberg。
6. 某源失败时该卡显示「暂无更新」，**不影响其他源**。
7. 同日数据与聊天「晨间财经简报」来自 **同一份 JSON 快照**。
8. 深色主题；排名 1–3 有视觉强调。
